# Download ufficiali Minefrax

Questo repository distribuisce esclusivamente i file per installare e aggiornare Minefrax. Non contiene i sorgenti del sito o delle mod personalizzate.

Apri le [Releases](https://github.com/thor469/minefrax-downloads/releases/latest) e scegli:

- **Minefrax-Setup-1.22.0-r3.exe**: installer Windows.
- **Minefrax-Survival.mrpack**: pacchetto per Prism Launcher e launcher compatibili.
- **release.json**: versione, dimensioni e impronte SHA256 dei file.

La release corrente richiede Minecraft Java 26.2 e Fabric 0.20.1. Server: **pro22.gamehosting.it:3193**.
